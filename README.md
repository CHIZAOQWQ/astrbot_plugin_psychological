# astrbot_plugin_psychological

心理委员插件 - 为群成员提供随机3次元美女图片

## 功能说明

这是一个 AstrBot 插件，当群成员输入 `/心理委员` 时，会随机回复一句温馨的提示语，然后从多个 API 中随机选择一个获取并发送一张图片。

## 使用方法

在群聊或私聊中输入以下命令：

```
/心理委员
```

插件会：
1. 随机回复一条提示语（如"稍等一下哦"、"希望这能让你心情好一点"等）
2. 从多个图片 API 中随机选择一个
3. 获取并发送图片

## 在 AstrBot 中管理 API

插件提供 WebUI 配置项，无需修改源码即可添加或删除 API：

1. 进入 AstrBot 插件管理页面。
2. 打开“心理委员，我不得劲”插件的配置。
3. 在“JSON API 地址列表”中添加返回 JSON、并通过 `data` 字段提供图片 URL 的接口。
4. 在“图片 API 地址列表”中添加直接返回图片或返回纯文本图片 URL 的接口。
5. 保存配置。若当前 AstrBot 版本不热重载插件，请手动重载插件后使用。

列表中的地址可以直接新增、编辑和删除。空列表表示禁用该类型接口；地址必须使用 `http://` 或 `https://`。

## API 请求测试

插件包含一个 AstrBot Pages 测试页面：

1. 重载“心理委员，我不得劲”插件。
2. 进入插件详情页并打开 Pages。
3. 选择“API 请求测试”。
4. 选择 JSON API 或图片 API，再选择要测试的地址。
5. 点击“测试当前接口”或“测试全部”。

测试会执行真实网络请求。JSON API 会继续检查响应中的图片 URL，图片 API 会检查图片响应；成功获取的图片会直接在页面中预览，同时显示 HTTP 状态、响应类型、图片大小和耗时。

## 特性

- 🎲 随机选择提示语，增加互动趣味性
- 🖼️ 支持多个图片 API，随机调用提高可用性
- ⚙️ 支持在 AstrBot WebUI 中动态管理 API 地址
- 🧪 支持在 AstrBot Pages 中测试接口并预览返回图片
- ⚡ 异步处理，响应快速
- 🛡️ 完善的错误处理机制

## 安装

1. 将插件目录放置到 `AstrBot/data/plugins/` 目录下
2. 在 AstrBot WebUI 的插件管理页面启用插件
3. 使用 `/心理委员` 命令即可

## 依赖

本插件使用 AstrBot 内置的 `aiohttp` 库，无需额外安装依赖。
